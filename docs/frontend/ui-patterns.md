# UI Patterns

Linted should feel focused, calm, and professional. It is a work tool wrapped in a social product, not a marketing toy.

## Layout

- Prefer dense but readable layouts for admin and operational screens.
- Keep public feed surfaces simple and clear.
- Avoid nested cards.
- Avoid decorative UI that does not help the user act.
- Make mobile states first-class, not afterthoughts.

## Controls

- Use icon buttons for known actions when an icon exists.
- Use clear text buttons for primary commands.
- Use dialogs only when the user needs focus or confirmation.
- Use tables with pagination for long admin datasets.
- Use explicit links when content should be read before navigation.

## Text

- Keep labels short.
- Do not expose raw database language to normal users.
- Avoid fake social proof or inflated claims.
- Use direct, helpful copy in errors.

## Accessibility

- Keep focus states visible.
- Ensure dialogs can close with keyboard and pointer.
- Do not rely on color alone for destructive actions.
- Confirm touch targets work on mobile.
