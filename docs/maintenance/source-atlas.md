# Source Atlas

The source atlas is generated by `scripts/docs/generate.mjs`.

## Outputs

- `docs/generated/source-atlas.md`: index of source files.
- `docs/generated/source-manifest.json`: hash manifest used to detect drift.
- `docs/generated/source/*.md`: one generated page per source file.

## What It Reads

The generator reads tracked and untracked non-ignored repository files from these areas:

- Root config and documentation files.
- `.github/`
- `app/`
- `components/`
- `docs/`, excluding `docs/generated/`
- `lib/`
- `public/`
- `scripts/`
- `supabase/`, excluding `supabase/.temp/`

## What It Extracts

- File kind.
- Purpose and edit guidance.
- Size, line count, and source hash.
- TypeScript imports, exports, functions, components, hooks, API handlers, interfaces, and type aliases.
- CSS selectors.
- SQL tables, policies, functions, triggers, indexes, views, and types.
- Related tests by naming convention.

## Rule

Never edit generated source pages by hand. Edit source or curated docs, then run `npm run docs:generate`.
