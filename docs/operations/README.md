# Operations

Operations docs explain how to run, check, deploy, and debug Linted.

## Main Commands

```bash
npm run dev
npm run test
npm run typecheck
npm run lint
npm run build
npm run docs:generate
npm run docs:check
npm run docs:lint
```

## Operating Rule

If a command changes generated files, commit those files with the code change that caused them.
