# Glossary

## Product Terms

- Linted: the product and community.
- Feed: the public resume feedback queue.
- Resume: a user-uploaded document or resume post.
- Review: feedback left on a resume.
- Helpful vote: a vote that promotes useful feedback.
- Trust: reviewer quality signal managed by app logic and admin controls.
- Linty: the mascot and brand character.
- Admin panel: private moderation and operations area.

## Technical Terms

- Next.js: the web framework used for pages, API routes, and production builds.
- App Router: the Next.js folder convention used under `app/`.
- React component: a reusable UI building block.
- TypeScript: JavaScript with static types.
- Supabase: hosted Postgres, auth, storage, realtime, and edge tooling.
- RLS: row-level security. Database rules that decide who can read or write each row.
- RPC: a database function called from the app.
- Migration: an ordered SQL file that changes the database.
- CI: automated checks in GitHub Actions.
- Source atlas: generated docs that map files and functions.

## Security Terms

- JWT: signed auth token that proves a session.
- Service role key: powerful Supabase secret used only on the server.
- Anon key: public Supabase key used by browser clients with RLS.
- Session refresh: process that renews an expired auth token.
- PII: personally identifiable information.
